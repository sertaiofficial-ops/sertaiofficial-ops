# SERTAI — Music, Code & Cinematic Storytelling

**Independent artist · Songwriter · Creative producer**

I'm Sertaç Avdaç, the creator behind SERTAI, an independent music project where songwriting, sound design, cinematic storytelling and digital technology come together.

*Behind every sound is a deliberate decision, not a mystery.*

My work begins with music and extends into the world surrounding it: visual narratives, digital characters, release campaigns, creative websites and experimental production workflows.

I use a combination of audio production software, vocal direction, AI-assisted visual tools and web technologies. These tools expand what I can create independently, while the artistic direction and final decisions remain my own.

## What I'm building

- **Music & sound:** Original songwriting, hybrid audio production and vocal direction.
- **Cinematic storytelling:** Connected visual narratives within the SERTAI Cinematic Universe.
- **Creative technology:** AI-assisted workflows for visual development and digital production.
- **Web & digital infrastructure:** Artist websites, publishing workflows, automation and practical tools supporting independent releases.

This GitHub space documents the technical side of that work: experiments, utilities, workflow improvements and projects developed around the SERTAI ecosystem.

*The story is in the visuals. The truth is in the music.*
